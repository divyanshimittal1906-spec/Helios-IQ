# Helios IQ architecture notes

This project follows a modular SaaS architecture designed for future AI employees and multi-agent workflows.

## Core principles

- multi-tenancy ready
- API-first design
- modular AI agent architecture
- environment-based configuration
- PostgreSQL + pgvector-ready data model
- isolated frontend and backend runtime boundaries

## Phase 1 foundation

- secure app shell
- auth-ready architecture
- workspace-first structure
- agent registry design
- PostgreSQL schema preparation
- health endpoint and environment config
